# Welcome to PeekKit

Folders and Markdown, together in Quick Look.

## Preview a folder

Select a folder in Finder and press **Space**. Click a subfolder to browse it, or select a file to preview it. Use the back button or breadcrumbs to return.

## Read Markdown

Select a `.md` file in Finder and press **Space**. Expand **View Markdown source** for the original text. In PeekKit and its folder browser, use the **Preview** and **Source** tabs.

| Feature | Included |
| --- | --- |
| Folder grid and list | Yes |
| Filtering, sorting, hidden files | Yes |
| Image, PDF, and text previews | Yes |
| Markdown tables and checklists | Yes |
